# Kahneman mechanisms for ad creative

Dùng khi map territory / giải thích Canvas. Giữ định nghĩa ngắn, **hướng hành động ads**.

| Cơ chế | Là gì (1 dòng) | Việc creative phải làm |
|--------|----------------|-------------------------|
| **System 1 / System 2** | S1 nhanh–cảm; S2 chậm–lười | Ads = S1; detail/giá = landing S2 |
| **WYSIATI** | Cái không thấy ≈ không tồn tại | Must-show claim trên frame |
| **Substitution** | Trả lời câu dễ thay câu khó | Chốt 1 “câu hỏi S1” |
| **Cognitive ease** | Dễ xử lý → tin/thích hơn | 1 ý, câu ngắn, fluent |
| **Mere exposure** | Lặp → quen → thích | Series tone cố định |
| **Affect heuristic** | Thích → tin benefit cao / risk thấp | Cảm xúc lead, feature theo sau |
| **Representativeness** | Giống prototype / “người như tôi” | Cast, nhà, đời sống khớp persona |
| **Availability** | Dễ nhớ → tưởng quan trọng/phổ biến | Vivid moment > thống kê khô |
| **Anchoring** | Số/ý đầu kéo đánh giá | Neo giá hoặc neo “giá trị dùng” |
| **Loss aversion** | Mất nặng hơn được (~2:1) | Frame “bớt mất” — không terror |
| **Prospect theory / fourfold** | Gain sure, loss sure, lottery, insurance | Chọn 1 ô cảm xúc chủ đạo |
| **Certainty / possibility effect** | Chắc chắn & hy vọng nhỏ bị overweight | Cam kết an tâm / dream nhẹ |
| **Endowment effect** | Đã “của mình” → khó bỏ | Trial, xếp đồ, “góc con” |
| **Halo** | 1 ấn tượng tốt loang hết | 1 hero shot/prototype đẹp |
| **Peak-end rule** | Nhớ đỉnh + kết, bỏ duration | Peak 0–3s; end mạnh |
| **Duration neglect** | Dài không = nhớ hơn | Spot ngắn đủ peak vẫn thắng |
| **Planning fallacy / inside view** | (Ít dùng ads thuần) | Tránh hứa timeline ảo |
| **Nudge / default** | Lười → theo mặc định | Opt-in mềm trên landing |

## Soft-sell mapping

| Tránh (hard) | Thay (S1 + CTA mềm) |
|--------------|---------------------|
| Mua ngay / chốt đơn | Xem chất liệu & size |
| Sale / giảm sốc | (để landing; ads kể khoảnh khắc) |
| Rẻ nhất / only today | “Chọn kỹ món dùng mỗi ngày” |
| Sợ độc / mẹ dở | “An tâm hơn với những gì chạm da” |

## Claim hygiene

- Chứng nhận **vải** ≠ cam kết y khoa cho bé.  
- % fiber + spandex: ads = cảm giác; landing = số.  
- 1 màu / ít SKU = tinh gọn (ease), không “xin lỗi thiếu màu”.
